관측 구간의 파일 변경 기여 집중도
주요 수정자 수는 관측 구간에서 파일 변경 커밋의 80%를 차지하는 최소 기여자 수입니다(식별된 기여 기준). 1은 한 명에게 관측 변경 기여가 집중되었다는 뜻이며 실제 지식 보유 인원이 아닙니다. 기여 분산도가 높다고 위험하다는 뜻은 아니어서 색을 붙이지 않았습니다. 기여자가 1명이면 정규화 기여 분산도는 0, 식별된 기여가 없으면 값이 없습니다(—).

함께 수정 (함께 변경된 파일 후보)
함께 수정 정도 = 함께 수정 횟수 ÷ min(두 파일의 변경 횟수)입니다. A → B는 A가 바뀐 변경 중 B도 함께 바뀐 과거 비율이고 B → A는 그 반대입니다. 미래 영향 확률이나 실제 의존성(import)이 아니며, 함께 수정 2건 이상인 쌍만 후보가 됩니다. 기본 정렬은 함께 수정 정도·함께 수정 횟수이고, IDF 보정은 자주 바뀌는 파일의 비중을 낮추는 실험 정렬로, 직접 선택해야 적용됩니다. 선택은 주소에 저장되어 탭을 옮기거나 뒤로 가도 유지됩니다.
