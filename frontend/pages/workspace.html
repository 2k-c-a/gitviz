시작하기

GitViz Workspace는 내 PC의 Git 프로젝트를 점검하는 도구입니다. 코드는 기본적으로 내 PC 밖으로 나가지 않습니다.

  1. 1프로젝트 폴더 등록
    Git 저장소가 있는 폴더를 고르세요. 폴더는 읽기만 하며 파일을 바꾸지 않습니다.
  2. 2변경 확인
    등록하면 바로 변경된 파일과 최근 커밋을 보여 드립니다.
  3. 3AI 점검 선택
    이 PC에 설치한 Ollama 모델이나 내 API 키가 있으면 사용할 수 있습니다. 모델은 자동으로 설치하지 않습니다.
  4. 4서버 연결 선택
    로그인하면 서버 분석과 함께 바뀐 이력을 볼 수 있습니다.

로그인이나 AI 없이도 Git 상태, 영향 범위, 테스트·린트 실행은 쓸 수 있습니다.

내 코드는 어디로 가나요?

기본적으로 코드를 어디에도 보내지 않습니다. 이 PC의 모델은 PC 안에서만 처리하고, 클라우드 모델은 보낼 내용을 직접 확인하고 동의한 부분만 보냅니다. 선택한 변경과 점검 결과는 이 PC의 암호화 저장소에 보관합니다.

    Git 상태

    변경

    점검할 파일을 고른 뒤 ‘점검 대상으로 담기’를 누르세요. 담은 변경은 스냅샷(그 시점의 고정된 사본)으로 저장되어, 이후 점검·검증·비교의 기준이 됩니다. 바이너리, 큰 파일, 비밀 값이 들어 있는 것으로 보이는 내용은 제외됩니다.

    

    조회와 담기는 읽기 전용입니다. 파일 적용과 프로젝트 검증은 별도 승인 후에만 실행됩니다. 외부 Git 메타데이터는 확인 후에만 읽으며, 서브모듈 안쪽 상태는 보여 주지 않습니다.

    점검할 대상이 없습니다. 먼저 에서 변경을 담으세요.
    

    


    

    

    ① 점검 대상
    담은 변경이 없습니다.

    클라우드 모델은 현재 계정으로 공개 저장소임을 확인한 연결에서만 쓸 수 있습니다. 앱의 월 사용 한도(USD 20)에는 아직 정산되지 않은 예약분도 포함됩니다.

    ④ 결과
    

    

    

    AI가 짚은 내용은 실제로 실행해서 확인한 결함이 아닙니다. 지적이 없다고 해서 결함이 없다는 뜻도 아닙니다. 취소해도 이미 보낸 내용은 되돌릴 수 없고, 결과를 알 수 없는 작업은 자동으로 다시 보내지 않습니다.
    

    


    

    개선 제안
    

    제안을 만드는 데 동의한 것은 파일 수정을 승인한 것이 아닙니다. 적용은 별도의 확인과 일회 승인을 거치며, 다른 도구가 고친 내용은 덮어쓰지 않습니다. 적용 중에는 원래 경로가 잠시 없을 수 있으니, 중단되면 복구 상태를 확인하세요. 스테이징·커밋·푸시는 하지 않습니다.
    

    복구가 필요한 제안
    

    

    제안이 없습니다. AI 점검에서 ‘작은 개선 제안’을 선택해 만들 수 있습니다.

    변경하기 전에 기준(baseline) 검증을 먼저 실행해 두세요. 측정하지 않았거나 실행 환경이 다르면 ‘비교 불가’로 표시합니다.
    

    

    


    

    영향 범위
    

    분석할 점검 대상이 없습니다. 먼저 에서 변경을 담으세요.
    

    Python·JS/TS 파서가 코드에서 읽어 낸 구문과 정적 연결만 보여 줍니다. 동적 호출과 외부 모듈은 알 수 없으며 실제 실행 결과를 뜻하지도 않습니다. 함께 바뀐 이력과 AI 추정은 따로 표시합니다.
    

    

    

    

    


    

    알림
    

    등록한 모든 프로젝트의 AI 점검, 테스트·린트, 개선 제안 적용 결과를 모아 보여 줍니다. 알림을 눌러도 화면만 이동하며, 코드 수정·명령 실행·전송은 하지 않습니다. AI 지적은 추정이고, 검증 실패는 실제로 실행한 결과입니다.
    

    





    

    

      

      


      

      계정·연결
      

      계정
      

      

      로그인은 선택 사항입니다. 로그인하면 서버 분석과 함께 바뀐 이력을 쓸 수 있고, 로그인하지 않아도 로컬 기능은 모두 쓸 수 있습니다.
      

      

      프로젝트 연결
      

      선택한 로컬 프로젝트(선택 안 됨)를 서버에 분석해 둔 저장소와 연결합니다. 코드는 보내지 않고, 로그인한 계정이 그 저장소를 볼 수 있는지 서버에서 확인합니다.
      


      

      현재 창에서 동시에 추적할 수 있는 연결은 최대 16개입니다. 한도에 닿으면 새 연결을 보류하며 기존 기록은 그대로 보존됩니다. 목록에서 저장소를 고르는 방식은 아직 지원하지 않아 번호를 직접 입력해야 합니다.
