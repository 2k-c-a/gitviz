## 미확정 사항

각 항목의 결정 담당자는 미지정이다. 필요한 역할을 제안할 뿐 특정 팀원에게 작업을 배정하지 않는다.

<a id="d01"></a>
### D01 — 결과·판단·메모 공유 정책

- **확인:** [과거 S13](../archive/originals/docs/AI_TEAM_ACCESS.md)은 역할·현재 접근·작성자 명시 공유의 교집합을 요구했다. 현재 [공유 router](../../app/api/ai/shared.py)는 현재 저장소 read만 확인하고 [조회 서비스](../../app/services/ai/shared_views.py)는 owner와 무관한 결과·메모를 반환한다. [개인 feedback](../../app/services/ai/feedback_service.py)은 여전히 결과 owner만 쓰게 한다. Git 이력 `b390f65`에 이 읽기 전용 공유 도입이 기록되어 있다.
- **확인:** [저장소 read 검사](../../app/services/repository_access.py)는 공개 저장소에서 조직 구성원·협업자 여부를 별도로 요구하지 않는다. 로그인한 비구성원도 공개 저장소 read가 가능하면 공유 결과 접근 조건을 만족할 수 있다. 이는 정적 경로 분석이며 이번에 실제 HTTP로 재검증하지 않았다.
- **추정:** 현재 안내는 ‘같은 저장소 구성원’보다 실제 검사 조건을 명확히 기술해야 한다.
- **미확정:** 공개 저장소 결과·메모의 대상 독자, opt-in 필요 여부, 기존 결과의 소급 공유, 원본 인용 공개 범위, 정책 고지·철회 조건. 제품·권한 담당의 결정과 공개/비공개 저장소별 인증 테스트가 필요하다. 코드를 과거 opt-in으로 되돌리거나 과거 계약을 오답으로 처리하지 않았다.

<a id="d02"></a>
### D02 — 계약 버전·호환성

- **확인:** [원본 계약](../archive/originals/docs/AI_INTERFACE_CONTRACT.md)은 의미 변경·삭제에 major 증가를 요구하면서 S12·S13 폐기를 1.9에 기록한다. [DTO](../../app/schemas/ai.py)의 현재 값도 1.9다. 보존한 S9는 v1.4를 가리키며 현재 UI 안내는 1.9와 실제 prefix를 명시했다.
- **추정:** 실제 공개 소비자와 폐기 전 사용 여부를 확인한 뒤 버전 규칙의 적용 범위를 정해야 한다.
- **미확정:** 개발 단계 예외인지, 버전 정책 위반인지, 향후 major 전환·deprecation 절차. API 담당·소비자 확인 필요. 문서만으로 코드 버전을 올리지 않았다.

<a id="d03"></a>
### D03 — 한도·profile 변경의 승인 근거

- **확인:** v0.4의 제안값, 기존 계약의 v1 한도, 제공자 문서의 v3 한도, 운영 문서의 v4 한도가 섞여 있다. 현재 [registry](../../app/services/ai/providers/registry.py)는 v4 노출, [원시 출력 상한](../../app/services/ai/providers/base.py)은 256KiB다. 기본 파일·일일 작업·대기 기한도 초기 제안과 다르다.
- **추정:** profile별 변경 사유·비용·context·동의 호환성·실측 검증을 연결해야 한다.
- **미확정:** 승인된 제품 한도와 현재 배포 설정, 각 모델의 실제 schema·품질·비용 검증. 현재값 설명은 [제공자 안내](../operations/providers.md)에 한정했다.

<a id="d04"></a>
### D04 — 운영 안내의 폐기 기능·로컬 예외

- **확인:** 기존 운영 보관 표에 팀 삭제 API가 남아 있다. 외부 전송 0을 ‘준비·조회만’으로 설명하지만 local_generate는 가능하다. 개인 금액 한도도 0이면 무제한인 구현과 ‘항상 적용’ 문장이 충돌한다.
- **정리 완료:** [현재 운영 안내](../operations/ai.md)에서 폐기 API를 제외하고 로컬 실행·0 한도의 예외를 명시했다. 오래된 안내는 보존소로 옮겼다. 사실 안내의 문서 충돌은 분리했다.
- **미확정:** 새 한도·공유·호환성 정책의 승인과 실제 배포 상태는 D01~D03의 별도 사항이다. 문서 수정 권한을 다시 요청하지 않는다.

<a id="d05"></a>
### D05 — 검증 기록의 출처와 현재성

- **확인:** 수용 보고는 운영 스냅샷 미확인을 기록하지만 Git에서 제외된 로컬 스냅샷 보고서는 별도의 과거 결과를 기록한다. 모순처럼 보이더라도 시점·환경·대역 여부가 다를 수 있다.
- **추정:** [증거 목록](../validation/evidence-index.md)의 실행 단위로 연결하고 출처가 확인된 경우에만 정식 기록으로 채택한다.
- **미확정:** 로컬 증거의 작성 커밋·보존·공유 가능 범위와 현재 재현성, 최신 운영·모델 평가·CI 상태. 과거 394개 검사를 현재 통과로 승격하지 않았다.

<a id="d06"></a>
### D06 — 과거 수집·시각화 과제 완료 상태

- **확인:** 전달 문서의 snapshot 이동·옛 지표 설명·작업 복구 등은 현재 보완 코드가 존재한다. 기여자 재생성·실수집 완전성은 별도 실행 근거가 필요하다.
- **추정:** 항목별 재현·수정 커밋·현재 회귀 결과로 종료 판정한다.
- **미확정:** 모든 과제의 담당·완료 여부. 신규 코드가 있다는 이유로 전체 브라우저·실연동 과제를 닫지 않는다.
