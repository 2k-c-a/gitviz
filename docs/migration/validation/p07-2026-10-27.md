# P07 에디터·검증 실행·비교 구현 추적

사용자는 P06 검증 후 P07 착수와 Q07의 VS Code·Cursor 초기 지원을 승인했다. 신규 의존성 설치나 운영 DB 변경은 포함하지 않는다.

| 요구 | 설계 | 구현 대상·재사용 | 검증·상태 |
|---|---|---|---|
| N04/C04/T05 | F04·09·S04 | 고정 editor adapter·native executable 선택·agent file scope | argv 단위 통과, 실제 에디터 인수 미실행 |
| N05/C05/T06 | F05·06·S04 | P04 immutable command_plan, validation/runner/diagnostics, native trust | suspended creation→Job Object→resume, 단위 실행 중, schema6 별도 승인 대기 |
| N07/C07/T08 | F07·06 | comparisons, encrypted snapshot after image, AST 실측 | 없는 baseline·다른 환경은 not_comparable, 구현 중 |

[P06 최종 기록](p06-2026-10-26.md)의 독립 패키지 gate가 통과했다. P03 실제 서버 OAuth·웹/앱 동시 사용 인수는 미완료다. P07 임시 SQLite migration·전체 단위·source Electron과 freeze/packaging은 각각 별도 승인 후 수행한다. 검증 코드는 같은 Windows 사용자 권한으로 실행되며 OS sandbox가 아니다. 출력은 ACL 보호 저장소에 암호화하고 renderer에 제한된 페이지로 반환한다. source/secret을 서버나 앱 로그에 기록하지 않으며 자동 재실행하지 않는다.

## 현재 증거

- `.validation/p07/runner-metrics-final.log`: runner·순수 지표 8개 통과. Unicode/공백/메타문자 argv, 별도 stdout/stderr, exit7, 닫힌 pipe 시간 초과, 취소, 출력 상한, 정상 부모 종료 후 grandchild 종료, 상대 실행 파일 거부, AST·diagnostic scope.
- `.validation/p07/host-tests.log`: host21개 통과. sandbox의 ACL 제한을 받는 2개는 일반 사용자 실행에서 검증했다.
- ESLint·TypeScript·Pyright 및 새 Python 모듈 Ruff 검사 통과. root Ruff 전체 규칙은 기존 workspace 파일의 import/typing 관련 36개 지적을 보이며 이번 단계에서 기존 파일을 일괄 재작성하지 않는다.
- VS Code의 `--goto file:line:column`은 [공식 CLI 문서](https://code.visualstudio.com/docs/configure/command-line)를 따른다. Cursor adapter의 동일 인자는 실제 설치본 검증 전 후보 상태로 남긴다. 기본 설치 위치의 두 에디터 실행 파일은 이 PC에서 발견되지 않았다. 설치·다운로드는 실행하지 않았다.

## 구현과 추가 검증 갱신

schema6의 validation_run/validation_approval/comparison과 project_setting.editorId를 구현했다. 이전 snapshot(schema3)·review(schema4)·proposal(schema5) 암호화 AAD는 유지한다. actual P05/v4·P06/v5 agent로 만든 자료의 백업·실패 rollback·성공 upgrade 및 FK 보존을 검사한다. 새로운 editor preference는 프로젝트별 CAS이며 실행 경로는 native 선택 후 앱 전용 main 설정에만 둔다. 실행 파일 이름·공식 publisher/제품 서명과 SHA256을 확인하고 변경 시 재설정을 요구한다. 고정 Windows PowerShell은 서명 조회에만 사용하며 경로는 stdin 데이터로 전달한다.

- `.validation/p07/workspace-tests-final.log`: 93개 통과(75.396초). 이후 실제 npm hook·원본 bytes·명시적 설치/수정 모드 거부 검사를 추가하여 최종 전체 검사를 재실행한다.
- `.validation/p07/npm-hooks-final.log`: 실제 설치 Node/npm의 pre/test/post 순서 통과. 사용자·전역 config를 같은 NUL로 지정하면 npm이 double-loading 오류를 내므로, 앱 소유의 서로 다른 빈 파일로 고정했다. 두 파일은 current-user ACL·빈 내용·identity/hash를 확인하고 실행 동안 read handle을 유지한다. 실제 사용자 npm config는 변경하지 않는다.
- `.validation/p07/electron-validation-final.stdout.log`: 실제 renderer/main/source agent/native 취소·신뢰 승인, Windows Job, baseline 성공→변경 후 실패, Python/JS·TS 지표, grandchild 취소, source/index 보존 통과. 마지막 source 검증 후 npm 빈 config 경로 변경을 반영해 재확인한다.
- `.validation/p07/host-tests-final.log`: 22개 통과. 공통 strict schema와 P07 위조 요청, JS/TS parser·argv를 포함한다.

비교 환경의 버전은 `runtime-config-lock-installed-metadata-v1`이다. 실행 파일/고정 CLI/빈 config의 바이트·프로젝트 입력/HEAD/index·설정·환경 allowlist를 재검사하고, 설치된 dependency metadata·선택 밖 프로젝트 파일의 fingerprint를 보관한다. 전이 의존성 코드 전체의 동일성을 증명하는 profile은 아니다. 범위/시간 상한·venv base 환경 미확인 등은 unknown이며 not_comparable로 표시한다. 명령의 같은 사용자 권한·파일/네트워크 side effect는 OS sandbox로 제한하지 않는다.

프로세스는 suspended로 만들고 kill-on-close Job에 할당한 뒤 재검사하고 resume한다. 정상 부모 종료 때도 남은 job 자식을 종료하며 active process 0을 확인한 뒤 terminal 결과를 반환한다. 120초/합계 1MiB의 상한과 stream별 원본 bytesBase64·UTF8 표시를 기록한다. 재시작은 running을 interrupted로 만들고 승인을 폐기하며 자동 재실행하지 않는다. 명시적 install/fix/write 모드는 후보 실행을 거부하고 Ruff에는 --no-fix를 고정한다. 임의 프로젝트 코드의 간접 side effect까지 차단한다는 보장은 하지 않는다.

지표는 고정 snapshot의 Python AST와 TypeScript 6.0.3 worker에서 함수·파일 분기 수 및 20-token exact window 중복을 실측한다. comments/whitespace만 정규화하고 symbol 이름/literal은 유지한다. 도구 버전·언어별 파일/토큰 분모·미지원 경로를 기록하며 측정하지 못한 값은 null이다. 이는 semantic clone·runtime complexity·품질 점수가 아니다. baseline/command/config/환경/scope가 맞지 않으면 검증 비교는 not_comparable이며 개별 test identity 전이와 속도·품질 개선은 근거 없이 만들지 않는다.

## 에디터 설치와 남은 화면 인수

사용자가 에디터 설치를 별도로 요청했다. 공식 [VS Code](https://code.visualstudio.com/docs/setup/windows) User Setup과 [Cursor](https://cursor.com/download)의 x64 User Setup을 다운로드하고 유효한 Microsoft/Anysphere 서명을 확인한 뒤 current-user로 설치했다. 설치 로그는 `.validation/p07/installers/`에 보존했다. 실제 제품 검증 함수로 확인한 버전·실행 경로·publisher·hash는 `.validation/p07/editor-installation.json`에 있다(VS Code1.143.1, Cursor3.27.14). 새 모델·확장 설치나 계정 로그인은 수행하지 않았다.

새 fixture profile에서 생성한 한글/공백/메타문자 경로의 파일을 --goto로 열었다. VS Code fixture 파일 창이 열리는 것은 inventory로 확인했다. Computer Use의 앱별 접근 승인이 `Computer Use app approval timed out`으로 끝나 커서의 실제 줄·열 화면 인수는 아직 통과로 표시하지 않는다. Cursor도 설치·서명·시작까지 확인하고 화면 인수는 남긴다. 별도 profile만 사용하며 실제 사용자 프로젝트나 기존 editor profile을 열지 않는다.

독립 `GITVIZ_VERIFY_P07=1` 패키지 entry는 `validation.e2e.js`, 검증기는 `scripts/validate_p07_package.ps1`로 준비했다. frozen agent는 별도 Python 설치를 필요로 하지 않지만 이 검증 명령의 unittest는 설치된 외부 Python을 의도적으로 사용한다. PATH 제한을 Python 미설치 증거로 오해하지 않는다. freeze/packaging은 별도 승인 대기이고 실제 서버 OAuth/웹·앱 동시 사용 인수는 계속 미완료다.

## 최종 승인 범위 검증 기록

`.validation/p07/workspace-tests-release.log`에서 전체96개가73.636초에 통과했다. 실제 npm pre/test/post, 원본 non-UTF8 bytes 보존, 설치/fix 모드 거부, 프로젝트 editor CAS, schema1~5→6·old ciphertext·rollback·backup·FK·재시작을 포함한다. 이후 UTF16 emoji 열 경계와 runtime/TEMP 변조 차단을 각각 `.validation/p07/editor-locations.log`, `runtime-environment-conditions.log`에서 추가 통과했다. 공식 서명 helper가 실제 두 설치본의 publisher/product/version을 검사했고 설치 증거 JSON에 SHA256을 보관했다.

`.validation/p07/preservation-audit.json`에서 시작 baseline 파일 누락0·server source 변경0, P05/P06 독립 패키지의 EXE/ASAR/agent 원본 hash 일치를 확인했다. 공통 schema fixture의 새 P07 위조 요청을 Python과 Node에서 재검증했다. 문서 구조/기존31개 원문 hash·링크 검사도 통과했다.

이 기록은 개발 호스트의 구현/fixture 증거다. frozen P07 패키지 실행 및 에디터 실제 줄·열의 화면 인수는 각각 승인/앱 접근 gate 뒤에 남아 있다. P03 실제 서버 OAuth·웹/앱 동시 사용 인수는 계속 미완료다.

## P07 승인된 frozen/패키지 검증 완료 — 2026-10-27

사용자가 agent 재빌드·기존 Electron 회귀·독립 P07 패키징을 승인했다. 동시에 **에디터 줄·열 화면 인수는 나중으로 연기**하도록 명시했다. 이 화면 인수를 통과나 취소로 바꾸지 않고 deferred gate로 유지한다.

- `.validation/p07/workspace-tests-final-all.log`: 전체97개 통과(77.677초). 완료 직후 snapshot 만료가 발생해도 실제 출력은 저장하고 진단/입력 조건은 unavailable/unknown으로 남기는 회귀를 포함한다.
- `.validation/p07/validation-final-private-cache.log`: 최종 고정 환경에서 실행/승인/실제 npm hook/전후 비교/만료 결과 보존7개 추가 통과. npm cache는 앱 전용 runner-npm-cache로 지정하고 logs_max=0으로 도구의 파일 debug 로그를 끈다. stdout/stderr 원본은 암호화된 run 결과에 보관한다.
- `.validation/p07/agent-build-final.log`: 최종 agent freeze 성공.
- foundation/projects/changes/auth/remote-compat/refactor 실제 Electron 회귀6종 통과. foundation의 preload exact allowlist는 P07의9개 named method만 추가했고 범용 invoke는 허용하지 않는다. E2E의 Chromium userData/sessionData/crashDumps는 생성한 임시 profile로 명시 분리하고 실제 경로를 foundation에서 검증한다.

구현 및 승인된 호스트/패키지 fixture 범위가 통과했다. N04의 실제 에디터 줄·열 화면 인수는 사용자 요청으로 연기됐다. 실제 서버 OAuth·웹/앱 동시 사용, 다른 PC 환경·clean VM 확대, 모델 품질·cloud BYOK, Q08 보존/삭제 최종 정책, installer/서명/배포는 완료로 승격하지 않는다. 기존 P05/P06 패키지 원본과 서버 소스 보호 검사를 유지한다.
