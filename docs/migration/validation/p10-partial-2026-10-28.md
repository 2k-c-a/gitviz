- 실제 Authenticode 검증기: 인증서가 없어 구현·검증하지 않았다. `SignatureVerifier` 인터페이스만 주입 가능하다. `install-update.ps1`의 `Get-AuthenticodeSignature` 경로는 유효 서명 파일로 실행해 보지 않았다.
- `releasePrefix`·publisher 실제 값, `forge.config.ts` maker/publisher, `.github/workflows/windows-release.yml`, installer 빌드·서명·배포.
- update.ts를 main 프로세스나 UI에 연결하는 작업(현재는 독립 모듈이다).
- 업데이트 설치 후 사용자 데이터 보존·롤백, clean VM 설치 인수.
