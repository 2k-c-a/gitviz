## 후속: 자체 서명 서명 검증 경로 시험

사용자 결정: 서명 없는 배포를 기본으로 두고 자체 서명 인증서로 서명 검증 경로를 한 번 시험한다. 공개 신뢰 서명은 지역·신원 요건 때문에 한국 졸업작품 팀에는 어렵다고 판단했다(Microsoft 문서 간 국가 목록이 달라 가입 전 재확인 필요).

- 관찰한 `Get-AuthenticodeSignature` 상태: 미서명 `NotSigned`, 자체 서명·루트 미신뢰 `UnknownError`(서명자 지문은 정상), 서명 후 변조 `HashMismatch`. `whoami.exe` 복사본은 OS 카탈로그 서명이 우선 보고되어 시험에 부적합했고, 끝에 8바이트를 붙여 카탈로그 일치를 깨뜨린 복사본을 사용했다.
- `install-update.ps1`에 `-PinnedThumbprint`를 추가했다(`-ExpectedPublisher`와 동시 사용 불가). 루트 미신뢰라도 서명자 지문이 일치하면 통과한다.
- `desktop/tests/self-signed-update.ps1` 실행 결과: pinned-ok 0, wrong-thumbprint 1, tampered 1, untrusted-root-as-public-publisher 1, no-publisher 2, 전체 통과. 종료 후 `Cert:\CurrentUser\My`에 시험 인증서 0개. 신뢰 저장소는 변경하지 않았다.
- 이 변경 뒤 `validate_workspace_windows.ps1`을 다시 실행해 23/23 통과, `statusChanged:false`를 확인했다(증거 `%TEMP%\gitviz-windows-0bbbe7c27658406d9b8e32b627cd4be7\evidence\summary.json`). `self-signed-update.ps1`은 그 23단계에 포함되어 있지 않아 별도로 실행한 결과다.
