## 구현 파일과 경계

- 서버: `app/api/desktop/repositories.py`, `app/main.py`. `GET /api/desktop/v1/repositories/{id}/identity`는 기존 인증·read 권한·numeric GitHub ID 검사를 재사용하고 accountId/repositoryId/githubId/canonicalUrl/visibility를 no-store로 반환한다. 공개 여부는 strict boolean 확인 후 public/private만 반환한다.
- 로컬 저장: `remote_schema.py`, `remote_connections.py`, `migrations.py`, `projects.py`. schema7→8에서 event CHECK 확장과 계정·origin·numeric ID·remote config hash 연결, 추적 job metadata를 추가한다. 과거 연결은 보존하고 active 연결을 교체한다. 연결 기록이 있으면 등록 해제를 보류한다. 파일 원본·Git remote를 수정하지 않는다.
- 알림: `events.py`, `notifications.py`, `dispatcher.py`. 첫 관측 terminal은 과거 알림으로 만들지 않는다. 이미 관측한 queued/running→done/failed만 같은 transaction으로 한 번 기록한다. job 상태 역행을 거부한다. 알림은 로컬 metadata이고 원격 결과를 캐시하지 않는다. 클릭은 현재 계정·권한·ID·remote hash를 다시 검사한다.
- main/IPC: `remote-workspace.ts`, `remote-workspace-ipc.ts`, `agent.ts`, `contracts.ts`, `remote-contracts.ts`, `main.ts`, `preload.ts`. renderer가 계정·origin·proof·config hash·raw URL을 지정하지 못한다. native 확인 후 연결한다. 계정 변경·로그아웃은 늦은 응답을 버리고 추적을 중단한다. 재로그인 시 저장한 연결에서 추적을 재개한다. 현재 창의 자동 추적 상한은16개이며 전체 원격 job 이력의 완전한 전달을 보장하지 않는다. 서버 status는 최신 job만 제공하므로 관측 사이에 교체된 job은 누락 가능하다. 종료 상태를 꾸며내지 않는다.
- cloud: `cloud_context.py`, `cloud_transport.py`, `review_transport.py`, `review.py`, `jobs.py`, `desktop/src/cloud-http.ts`, `cloud-review.ts`, `projects.ts`. 사용자 입력의 일시 renderer 상태를 제외하면 API 키는 **main의 일시 메모리에만** 존재하고 agent RPC·DB·preview·로그로 전달하지 않는다. 5분 만료/계정 변경/닫기 시 참조를 해제한다. 언어 런타임의 메모리 zeroization은 보장하지 않는다. agent는 30초 공개 매핑 증명과 고정 요청 bytes/hash만 다룬다. main이 native 동의 후 fresh 증명과 bytes를 다시 확인하고 고정 HTTPS provider로 한 번 전송한다. proxy·redirect·자동 재시도·fallback 경로는 없다. 오류 응답 원문과 키 반사 응답은 agent에 넘기지 않는다. provider wire/출력 검증은 workspace schema를 사용한다. 실제 provider 호환성·품질은 미검증이다.
- 비용: 고정 profile 가격으로 최대 입력/출력 예약을 산정하고 실제 usage로 정산한다. 기존 서버 기본값과 같은 USD20/달을 앱 전체에 적용한다. 계정·키를 바꿔도 해당 앱 ledger의 미정산/uncertain 예약은 남는다. provider 실제 청구와 다를 수 있고 다른 PC/서버 사용량을 합산하지 않는다. usage 누락은 예약을 해제하지 않는다.
- UI: navbar/page-context에서 query의 repo/snapshot 의미를 보존한 workspace 진입만 제공한다. query는 연결 권한이 아니다. 프로젝트 연결, 앱내 원격 분석 알림, provider/일시 BYOK 선택과 실제 전송·비용 표시를 추가했다. `frontend/js/platform/workspace-navigation.js`, workspace `projects.js/review.js/inbox.js/navigation.js`, `workspace.html` 및 navbar 관련 파일이다.
- 진단: `diagnostics.ts`, `diagnostics-ipc.ts`. native 저장 선택 후 새 파일에 버전·component 상태만 쓴다. 계정·키·경로·소스·DB·원본 로그는 내보내지 않는다. 기존 목적지 파일을 덮어쓰지 않는다.
- 공통 계약: `contracts/workspace/v1/request.schema.json`, `response.schema.json`, Python/TS operation 목록. protocol1·schema8, strict request/response. cloudContext는 key 필드를 거부하고 cloudExchange는 main 전용이다. source bytes는 renderer에 raw IPC로 노출하지 않는다.

자동 승인 검토는 agent로 BYOK 키를 넘기는 후속 패치를 거부했다. 거부된 경로는 사용하지 않으며, 앞서 작성 중이던 agent network/key 처리도 제거했다. 현재 cloud codec은 순수 함수이고 실제 HTTPS·키 처리는 main에만 있다. CI 설정과 schema 경계의 최초 거부는 각각 명시 승인 후 반영했다.
